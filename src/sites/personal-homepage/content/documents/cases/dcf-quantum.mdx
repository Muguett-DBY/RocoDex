<LocaleBlock locale="zh">

<ArchiveSection id="principle" title="估值必须能被复算。" eyebrow="01 / 原则">

软件不调用大模型，也不自动交易。悲观、中性和乐观区间由公开、确定性的 Python 公式产生，并保留实际折现率口径。

</ArchiveSection>

<ArchiveSection id="audit" title="每次扫描都有数据血缘。" eyebrow="02 / 审计">

运行清单记录模型版本、配置哈希、数据指纹、缓存参数、依赖版本与输出哈希。代理结果与已完成 FCFF 桥接的确认结果明确分离。

</ArchiveSection>

<ArchiveSection id="desktop" title="把研究内核交付给没有 Python 的电脑。" eyebrow="03 / 交付">

Windows x64 安装包包含本地浏览器 GUI、独立工作进程、安全取消和离线体验；服务只监听本机回环地址。

</ArchiveSection>

</LocaleBlock>

<LocaleBlock locale="en">

<ArchiveSection id="principle" title="A valuation must be reproducible." eyebrow="01 / Principle">

The software calls no language model and makes no trades. Bear, base, and bull ranges come from public deterministic Python formulas with the applied discount-rate basis retained.

</ArchiveSection>

<ArchiveSection id="audit" title="Every scan carries data lineage." eyebrow="02 / Audit">

Run manifests retain model version, config hash, data fingerprint, cache parameters, dependencies, and output hashes. Proxy estimates remain explicitly separate from FCFF-bridged confirmations.

</ArchiveSection>

<ArchiveSection id="desktop" title="Ship the research core to machines without Python." eyebrow="03 / Delivery">

The Windows x64 package includes a browser GUI, isolated worker process, safe cancellation, and offline demo, bound only to loopback.

</ArchiveSection>

</LocaleBlock>
