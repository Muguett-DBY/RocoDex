# CSTD Project Brief Copy Design

## Problem

Project focus links are shareable, but the recipient still needs to open the page before seeing the project's role, problem, and delivered outcome. There is no compact text brief that can be pasted into chat, notes, or a portfolio handoff.

## Decision

Add a project brief builder and a `复制案例摘要` action inside the focus panel. The copied text is plain, stable, and evidence-based: title, current state, role, problem, delivered outcome, and project URL.

## Acceptance

- Brief text is generated by a tested pure helper.
- Focus panel offers a separate copy action for the brief.
- Copy result feedback is distinct from the focus-link copy feedback.
- Failed or unsupported clipboard attempts reveal a read-only brief text fallback.
- Changing focus projects clears stale brief-copy feedback.
- Desktop and 390px mobile verification show no overflow or console errors.
