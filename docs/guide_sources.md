# 攻略页来源说明

`/guides` 汇总 PVE / PVP 强度榜与培养建议。当前首版优先复用本项目已有图鉴 seed data 与 `/pvp-teams` 当前 META 数据。

## 来源口径

- BWiki 精灵图鉴：用于确认基础条目、编号、名称、属性、形态和图片来源页。
- `/pvp-teams` 当前 META：用于整理 2026-04-15 之后 PVP 阵容中出现过的精灵、定位、阵容来源和部分培养建议。
- 旧版 PVP 资料只作为历史参考，不进入 `/guides` 当前 PVP 评级。

## 可信度

- `confirmed`：可靠来源明确给出完整培养结论。
- `partial`：来源能确认阵容、定位或部分推荐，但仍缺少完整培养核验。
- `analysis`：来源只给出思路或阵容，性格、天分、配招由本站按定位分析。
- `unknown`：缺少可靠培养来源，必须显示“未评级 / 待复核”。

## 字段来源标记

- `source-derived`：公开来源明确给出的字段。
- `analysis-derived`：本站按已确认定位、阵容或打法推导，页面必须显示“本站分析”。
- `unknown`：缺少资料，页面必须显示“待复核”。

## 维护规则

- 不得为了补齐页面而编造配招、性格、天分或评级。
- 新增 PVP 评级时，应同步记录来源链接、发布日期、来源等级和资料口径。
- 新增 PVE 评级时，应至少记录公开攻略或可核验的技能/副本资料来源。
- 图片仍沿用现有本地缓存或占位图，授权状态保持 `needs-review`，直到逐张确认。
