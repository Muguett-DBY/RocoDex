# CSTD visual system

## Direction

CSTD is an original warm cyber-engineering world: tactile research materials and precise browser instrumentation, without borrowed characters, logos, or interface motifs from entertainment IP.

The homepage is the cinematic overview. Deep routes are quieter archives: real images remain first-viewport signals, typography carries hierarchy, and interaction reveals system behavior rather than adding search or comparison tools.

## Palette

| Token | Value | Use |
| --- | --- | --- |
| Signal black | `#050709` / `#080a0c` | World and instrument backgrounds |
| Archive paper | `#f1eee5` | Long-form reading surfaces |
| Custard | `#f4d431` | Primary identity, proof, and current state |
| Cyan | `#24e0ff` | Data flow, links, and system state |
| Safety red | `#ff5a50` | Stale or rejected state only |
| Confirmed green | `#3dff8f` | Verified live state only |

Yellow and cyan must not become full-page monochrome themes. Paper bands and true black maintain contrast; red and green carry semantic meaning rather than decoration.

## Signature moments

1. **Neural Gate:** the homepage boots into one continuous WebGL city while semantic content remains in the DOM.
2. **Archive transition:** route navigation uses the native View Transition API when available, with an ordinary Next navigation fallback.
3. **Proof ledger:** case studies reverse from black instrumentation to custard paper, separating claims from delivery evidence.
4. **Local instrument:** each Lab turns one engineering relationship into a focused control surface.

## Motion budget

Deep pages expose Full, Balanced, and Calm modes. The explicit site choice is persisted in `localStorage`; operating-system reduced-motion is not allowed to silently erase the designed experience. Calm mode removes continuous particles and pulses while retaining layout, hierarchy, focus, and state transitions.

The deep-route canvas caps DPR, pauses meaningful work while hidden, draws no remote images, and never owns text or navigation. The homepage keeps Three.js behind its existing lazy scene boundary.

## Asset policy

- Use real project captures for work evidence.
- Use the existing original `cstd-world`, `cstd-archive`, and `cstd-universe` image families for conceptual pages.
- Never render readable generated UI or fake metrics inside images.
- Every image requires localized alt text and stable responsive dimensions.
- Generated source art must be converted to an optimized project asset before code references it.
