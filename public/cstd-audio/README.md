# CSTD audio assets

These local audio files are used by the CSTD main-site intro and sound controls.

## Current source

- Source: OpenGameArt, "4 Music Box Tracks" by Aureolus_Omicron.
- URL: https://opengameart.org/node/136996
- License: CC0 / public domain dedication. The source page states: "CC0. No credit required."
- Download used: `4_music_box_tracks_ogg.zip`
- Source files used:
  - `musicbox4_happy_polka.ogg` -> `intro-custard-stinger.wav`
  - `musicbox2_cute_tune.ogg` -> `custard-warm-loop.wav`
  - `musicbox4_happy_polka.ogg` -> `custard-pop.wav`

## Intended sound direction

The target is a bright "cream music box" feel: celesta/music-box tones, soft bells, warm and cute, with no bass drone, dark ambience, horror mood, chiptune, or 8-bit texture.
